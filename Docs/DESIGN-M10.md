# M10 — 집중과 파장

M9으로 자취가 보이게 됐는데 **늘 보여서 과하다**. 화면이 냄새로 덮이면 그것대로
아무 정보가 없는 것과 같다. 냄새는 **집중할 때만** 맡는 것으로 바꾼다.

같은 자리에서 청각도 손본다. 소리가 화면 가장자리의 호로만 뜨는데, 소리가 **난 자리**에
파장이 퍼지는 편이 훨씬 읽기 쉽다.

## A. 집중 상태

- Q를 **누르고 있는 동안** 집중한다(액션 이름 `Focus`, 이미 `ByAWhisker.inputactions`에 넣어 두었다).
- 집중하면 두 가지가 일어난다.
  1. 카메라가 캐릭터 쪽으로 다가온다. 거리와 시야각이 부드럽게 줄었다 돌아온다.
  2. 냄새 자취가 드러난다. 0에서 1로 부드럽게 오르고, 놓으면 부드럽게 사라진다.
- 새 컴포넌트 `Player/FocusSense.cs`.
  - `public bool IsFocusing`
  - `public float Amount` — 0..1. 켜고 끌 때 뚝 끊기지 않게 보간한 값.
  - 이 값을 전역 `_BW_ScentReveal`(float)로 넣는다. 셰이더가 이걸 곱한다.
- `QuarterViewCamera`에 집중용 거리/시야각을 더한다. `public void SetFocus(float amount)`로
  0..1을 받아 평소 값과 집중 값 사이를 섞는다. 카메라가 스스로 입력을 읽지 않게 한다 —
  지금도 회전은 밖에서 넣어 주는 구조다.
- `PlayerInputReader`에 `public bool FocusHeld`를 더한다. 사격과 같은 방식이다(이벤트가 아니라 상태).

건드리는 파일: `Player/FocusSense.cs`(새 파일), `Player/PlayerInputReader.cs`, `Cameras/QuarterViewCamera.cs`.

## B. 소리 파장

소리가 난 자리에서 고리가 퍼졌다 사라진다. 화면 가장자리의 호가 방향만 알려 준다면,
파장은 **어디서 났는지**를 그대로 알려 준다.

- 새 컴포넌트 `Senses/NoiseRipple.cs`. `NoiseBus.Emitted`를 구독해 소리마다 고리를 하나 띄운다.
- 고리는 소리의 `radius`까지 퍼지고 옅어진다. 퍼지는 시간과 색은 직렬화 필드로.
- `NoiseKind`로 색을 가른다. 발소리와 총성이 한눈에 갈려야 한다.
- 고리는 미리 만들어 재사용한다. 소리마다 `new GameObject`를 만들지 마라.
  `LineRenderer`를 원형으로 굽히는 방식이면 충분하다. 매 프레임 할당 금지.
- 고리는 바닥에 눕힌다. 벽을 뚫고 보여도 된다 — 소리는 벽을 돌아 들리니까.
- 집중과 무관하게 늘 보인다. 듣는 것은 눈을 감아도 들린다.

건드리는 파일: `Senses/NoiseRipple.cs`(새 파일).

## C. 자취 강도 낮추기

- `VisionComposite.shader`가 전역 `_BW_ScentReveal`(float, 기본 0)을 곱한다.
  집중하지 않으면 0이라 자취가 아예 안 뜬다. 전역이 없을 때 0으로 읽히는 것이 맞다 —
  실수로 늘 보이는 것보다 안 보이는 쪽이 낫다.
- 지금 `_ScentGlow` 2.5는 과하다. 1.2쯤으로 낮추고, 셰이더 쪽에서 세기를 한 번 더
  눌러 옅은 자취가 뭉개지지 않게 해라(예: 세기에 감마를 먹이거나 상한을 둔다).
- `ScentMapRenderer`는 신선도 반감기만 손본다. 12초는 25초짜리 자취에 비해 짧다.

건드리는 파일: `Shaders/VisionComposite.shader`, `Senses/ScentMapRenderer.cs`.

## 규칙

- 공개 멤버와 전역 이름을 위에 적은 대로 맞춘다.
- 맡은 파일 밖은 읽기만 한다.
- 숫자는 코드에 박지 않는다. 직렬화 필드로 뺀다.
- 매 프레임 할당을 만들지 않는다.
- `.meta` 파일을 만들지 않는다.
- 주석은 한국어로, 무엇이 아니라 왜를 적는다.

## 통합 메모

**합성 패스의 주입 시점을 옮겼다.** `BeforeRenderingPostProcessing` → `BeforeRenderingTransparents`.
소리 고리는 `LineRenderer`로 그리는 투명 물체라, 어둡게 만드는 전체화면 패스가 투명 물체
다음에 돌면 고리까지 검게 칠해진다. 소리는 벽을 돌아 들리니 고리도 어둠을 넘어야 한다.
불투명 물체를 어둡게 만든 뒤에 투명 물체를 그리면 고리가 그 위에 남는다.

이 바꿈의 대가: `AimTelegraph`의 조준선도 같은 투명 버킷이라 이제 어둠을 뚫고 보인다.
경비가 나를 겨누고 있다는 예고가 어둠 속에서도 보이는 셈인데, 한 대에 죽는 게임이라
그 예고는 보이는 편이 낫다고 판단했다. 마음에 안 들면 조준선을 불투명으로 옮기거나
고리를 따로 겹쳐 그리는 쪽으로 바꾸면 된다.

머티리얼 값: `_ScentGlow` 2.5 → 1.2, `_ScentGamma` 0.65.

## 확인한 값 (플레이)

- 집중을 끄면 전역 `_BW_ScentReveal`이 0이고 자취가 화면에 한 픽셀도 뜨지 않는다.
  셰이더가 0일 때 블록 자체를 건너뛰므로 M9 이전 화면과 같다.
- 집중을 켜면 같은 화면에 자취가 뜬다. M9 때보다 눈에 띄게 옅다.
- 카메라 거리 10.5 → 6.5, 시야각 45 → 38.
- 소리 고리가 플레이어가 못 본 검은 자리에서도 또렷하게 보인다. 발소리는 청록, 총성은 주황.
- 고리 풀 16개로 돌아간다. 소리마다 오브젝트를 만들지 않는다.
