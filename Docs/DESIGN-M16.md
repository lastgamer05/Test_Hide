# M16 — 총은 마지막 수단, 경비는 쉬지 않는다

## 왜

"그냥 총으로 다 죽이면 된다"는 피드백. 원인은 체력이 아니라 총알 수와 소리였다.

- 탄창 6 + 예비 6 = 12발. 경비도 12명이라 한 발에 한 명씩 전부 잡을 수 있었다.
- 권총에 소음기가 달려 총성 크기가 0.9 x 0.15, 반경 12를 곱하고 경비 청각 0.6을 곱하면 **약 1m**에서만 들렸다.

한 방에 죽는 규칙은 양쪽 다 그대로 둔다. 여러 방으로 바꾸면 총을 쏘고 버티는 게임이 되고, 총알을 줄이는 것과
결과는 같은데 쏘는 맛만 나빠진다.

그리고 "경비가 너무 가만히 있다". 순찰로 12개 중 5개의 `points` 목록이 끊긴 참조(`{fileID: 0}`)만 들고 있어서
`PatrolRoute.Resolve()`가 빈 목록을 돌려줬고, 그 5명은 시작 자리에 굳어 있었다.

## 바뀐 것

**총알** (`PlayerPistol.asset`): 탄창 3, 예비 0. 시작 3발.
**탄약 상자** (`AmmoPickup`): 밟으면 예비탄 +2. 순찰로에서 조금 벗어난 곳 4개 — (25,35) 좁은 세로 통로,
(3,9) 북서 방 구석, (77,3) 북동 방 구석, (77,19) 동쪽 벽가. 최대 3 + 8 = 11발 < 경비 12명.
재시작하면 되살아나고, 플레이어 탄약도 재시작 때 채운다(`PlayerCombat`이 RunReset에서 `RefillAmmo`).
안 채우면 잡혔다 다시 주워 무한히 쌓을 수 있었다.

**총성** (`WeaponSettings.noiseRadius`, `NoiseEmitter.EmitOnce(loudness, kind, radius)`): 권총 소음기 뗌,
크기 1, 반경 30. 경비 청각 0.6을 곱해 **18m**. 경비 소총은 `noiseRadius` 0이라 예전 그대로다.

**경보 단계** (`StationAlert`, `StationAlertSettings`, `AlertHud`): 한 판(한 목숨) 동안 내려가지 않는다.

| | 평상 | 경계 | 비상 |
|---|---|---|---|
| 오르는 조건 | — | 경비가 시체를 처음 발견 | 경비가 Alert(플레이어 확인) 또는 시체 2구째 |
| 순찰 속도 | x1.0 | x1.25 | x1.45 |
| 순찰 지점 대기 | x1.0 | x0.6 | x0.35 |
| 손전등 범위(판정과 조명 둘 다) | x1.0 | x1.2 | x1.35 |
| 알아채는 시간 | x1.0 | x0.85 | x0.7 |
| 수색 시간 | x1.0 | x1.3 | x1.6 |

단계가 올라도 경비는 플레이어 위치를 새로 알지 못한다. 시체를 본 경비만 외친다(기존 외침 재사용).
화면 위 가운데에 "경계"(주황) / "비상"(빨강) 표시, 평상에는 안 보인다. 설정 에셋은 없어도 코드 기본값으로 돈다.

**순찰**: 끊긴 `points`는 비우고, `Resolve()`가 살아 있는 지점이 없으면 자식으로 돌아가게 했다(다른 세션의 수정).
순찰 지점 대기 1.2초 → 0.6초.

**버그 두 개**
- 플레이어가 총에 맞아 쓰러질 때 `Damageable`이 CharacterController를 트리거로 바꾸려다 오류를 냈다. 건너뛴다.
- `ThrowAction`이 RunReset을 OnEnable에서 받아서, 쓰러져 꺼진 동안 오는 재시작을 놓쳤다(돌 개수가 안 참). Awake로 옮겼다.

## 측정 (플레이 모드)

- 순찰: 9.3초 동안 12명 모두 6.6~18.6m 이동(수정 전 5명은 0m).
- 시작 탄약 3+0, (3,9) 상자 밟자 3+2.
- 총성: 12m 경비는 의심도 0 → 0.9, 수색 시작. 20m 경비는 0 그대로.
- 경비 앞 3m에 시체: 경보 1, 순찰 속도 2.0 → 2.5, 손전등 9 → 10.8, 화면 "경계". 비상에서 손전등 12.15.
- 재시작: 경보 0, 시체 수 0, 탄약 3+0, 상자 4개 복구, 손전등 9.
- 플레이어 사망 후 콘솔 오류 0, 되살아난 뒤 돌 3개.

## 남은 것

- 총성 파문(집중 상태에서 보임)은 반경 30m 그대로 그린다. 경비가 실제로 듣는 것은 18m다.
- 이미 Alert/Attack인 경비는 총성을 청각 배율 없이(30m) 받아 엄폐하러 간다.
- 탄약 상자는 호박색 정육면체. 모델이 필요하면 `visualPrefab`에 넣는다.
- 경비 5·6·7·8의 시작 자리가 순찰로 첫 지점에서 멀다(처음 수십 초는 제자리로 걸어간다).
